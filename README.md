
GitHub Repository Collector

A Python-based automation tool designed to streamline open-source intelligence gathering by querying the GitHub Search API and compiling repository information into a structured CSV spreadsheet. This tool serves as the foundational project in a planned series of modular infrastructure, scripting, and security automation tools.

📌 Project Overview

Manual gathering of open-source repository statistics, descriptions, and metadata for analysis can be tedious. This tool automates the entire ingestion pipeline: it accepts user-defined search parameters, communicates securely with GitHub's developer endpoints, parses the JSON payload, and formats the output into a clean dataset ready for analytical tools or spreadsheet applications.

📂 Architecture & File Structure

The project is built with modularity in mind, separating concerns across three core execution scripts:
• main.py
The primary execution runtime and command-line user interface. It handles user inputs, initializes the system configuration, coordinates the data orchestration between the API scanner and the export handler, and manages basic logging and terminal runtime output.
• github_collector.py
The dedicated integration engine for external connectivity. It interfaces directly with the GitHub Search API endpoints, translates user text strings into structured API query parameters, handles request headers (including authentication/token payloads if configured), monitors API rate-limiting thresholds, and processes raw JSON responses into flat Python objects.
• csv_exporter.py
The downstream data processing module. It consumes structured data lists or dictionaries generated by the collector, validates the schema fields (such as repository name, owner, stars, forks, and description), handles character encoding configurations to prevent formatting corruption, and writes the output cleanly to an accessible CSV spreadsheet.

🚀 Getting Started


Prerequisites

• Python 3.x
• An active internet connection (to reach GitHub's endpoints)
• requests library (if using standard HTTP networking)

Setup & Usage

1. Clone this repository or move into your local workspace directory:bash
cd /home/vboxuser/github_repo_collector

2. Execute the automation pipeline script:bash
python3 main.py

3. Follow the terminal prompts to input your search query (e.g., search keywords, language requirements, or topic tags).
4. Find your generated data snapshot file saved in the root folder as a .csv file.
